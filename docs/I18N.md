# 工具箱国际化（core/i18n）

> 状态：**已落地**（语种元数据 + `content` 分区；可翻译词进 JSON；快捷键、标点、分隔符在代码）

## 一、语种文件结构（`core/i18n/{code}.json`）

每个文件包含 **`locale`**（语种元数据）与 **`content`**（可翻译文案）：

```json
{
  "locale": {
    "order": 1,
    "code": "zh",
    "name": "简体中文",
    "isDefault": true
  },
  "content": {
    "brand": { ... },
    "common": { ... },
    "message": { ... },
    "page": { ... }
  }
}
```

| `locale` 字段 | 说明 |
|---------------|------|
| `order` | 语言列表排序（数字越小越靠前） |
| `code` | 语种编码（与文件名一致，如 `zh`、`en`） |
| `name` | 语言选择页显示名（如「简体中文」） |
| `isDefault` | 仅一个语种为 `true`；未配置时取注册表第一项 |

**新增语种：** 在 `core/i18n/` 增加 `{code}.json` 即可，无需改 `page.lang` 或其它注册表。删除文件即移除该语种。

**向后兼容：** 若 JSON 无 `content` 顶层，则除 `locale` 外的顶层键均视为 `content`（便于旧文件过渡）。

## 二、`content` 内分区

| 分区 | 内容 |
|------|------|
| **brand** | 品牌：标题、作者名、描述、欢迎语 |
| **common** | 通用词（扁平）：`menu`/`option`/`help`/`command`/`tool`/`language`、分页、`cmd` 子对象等 |
| **message** | 各类提示（扁平一层）：退出确认、闪提示、错误、警告等 |
| **page** | 各页面专属文案（不含语种列表） |

## 三、原则

| 进 i18n | 不进 i18n（`I18n.ps1` 常量或拼装） |
|---------|-------------------------------------|
| 确认、返回、作者（标签词）… | `Y`、`Enter`、`Esc`、`↑↓`、`←→` |
| 完整句子、页面标题 | `：` 标签分隔、` \|  ` hint 分隔、`( shortName )` |
| | `v1.0 · 2026-05-28` 等版式 |
| | 底栏快捷键：`Format-I18nKeyDisplay` → `[Esc] 退出`、`[Enter] 确认`（经 `Get-I18nKeyHint` / `Get-I18nArrowHint`） |

## 四、API（摘要）

| API | 示例 |
|-----|------|
| `Get-ToolkitLocaleRegistry` | 扫描 `core/i18n/*.json`，按 `order` 排序 |
| `Get-DefaultToolkitLocale` | 读 `isDefault: true` 的语种 |
| `Get-LocaleDisplayName` | 读 `locale.name` |
| `Get-I18n -Key 'brand.welcomeLine'` | 欢迎语 |
| `Get-I18nKeyHint -Key $script:I18nKeys.Esc -LabelKey 'common.quit'` | `[Esc] 退出` |
| `Get-ToolkitI18n -Key 'common.confirm'` | 工具脚本用工具箱文案 |

代码常量：`$script:I18nHintSeparator`、`$script:I18nLabelSep`（`：`）、`$script:I18nKeys`。

## 五、工具侧 i18n（与工具箱格式不同）

- 路径：`tools/<id>/i18n/{code}.json`；**`{code}` 与文件名一致**，跟随工具箱当前界面语种（`Get-CurrentLocale`）。
- **无** `locale`、**无** `content`：顶层直接是文案键（扁平 JSON）。
- **加载方式**：各工具 i18n **不合并**进工具箱全局 catalog；`Get-ToolI18nRaw` 始终带 `ToolRoot`，只在对应工具的 json 里查键。首次访问某工具某语种时读盘，结果缓存在 `$script:ToolI18nCatalogCache`（键为 `ToolRoot|locale`），会话内复用；**不会**在用完后销毁。`Discover-Tools` 为首页列表会**预先**加载每个工具的 i18n（解析 `name` / `description`），进入工具内菜单时再按需加载 action 等键。
- **层级结构**：`i18n/{code}.json` 以 **`command` 为顶层键**，其下嵌套文案，避免每个键重复写工具名。示例：
  ```json
  {
    "node": {
      "name": "Node.js 版本管理",
      "description": "...",
      "action": {
        "install": { "name": "浏览并安装", "description": "..." }
      }
    }
  }
  ```
  `index.json` 的 `name` / `description` / `dependencies.menus.*` 填**全路径 i18n 键**（如 `node.deps.install`）。依赖菜单**名称**用 core `page.toolDeps.*Label`；**介绍**按 `dependencies.menus` 解析，未配则用 core 默认。
- `Apply-ToolI18nFields` 按当前语种解析后写入工具对象；缺 name 键时显示 `common.unrecognized`（无法识别）。
- 旧试点若仍含 `content` / `locale`，加载时会忽略 `locale`、优先读 `content`（过渡兼容）。
- 工具可调用 `Get-ToolkitI18n` 使用工具箱公共词；**不得**读取其它工具的 i18n，工具箱也**不**读工具 json。

详见 [TOOL-CONVENTION.md](TOOL-CONVENTION.md)。

## 六、切换语种

用户通过 `miao lang` 或 `config.json` 的 `locale` 切换；`MIAO_LANG` 环境变量可覆盖（开发用）。
