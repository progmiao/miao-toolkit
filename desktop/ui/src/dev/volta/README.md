# Volta 专用页

本目录仅服务 **Volta** 工具本体（WinGet 安装 / 卸载），与 Node / Pnpm / Yarn 页面互不共用模板。

- 页面：`index.vue`
- 公共：`JobConsole` + `useJobConsole`
- Host：`generic.winget` / `generic.winget-uninstall`（`Miao.Software/Install`）
- 版本查询服务仍在：`Miao.Software/Dev/Volta`
- 种子：`seeds/dev/volta/software.json`（`ui.entry: "volta"`）
